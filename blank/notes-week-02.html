    Handout Tuesday 9/8

    Objectives

    • Compute limits of functions using the limit laws.
      🔗
      🔗
    • Compute limits of indeterinate form limits using algebraic cancellation, radical simplification, or special limits.
      🔗
      🔗

    Indeterminate Forms.

    Before we get started on new topics for today, let’s review the direct substitution property from last class.
    🔗

    Theorem 29.

    Let \(f\) be a function and \(a\) a real number. If \(f\) is:
    • a polynomial or algebraic function without denominator, or
      🔗
      🔗
    • a rational function of the form \(f(x) = \frac{P(x)}{Q(x)}\) where \(P\) and \(Q\) are polynomials and \(Q(a) \neq 0\)
      🔗
      🔗
    Then
    \begin{equation*} \lim_{x \rightarrow a} f(x) = f(a)\text{.} \end{equation*}
    🔗
    🔗
    🔗

    Example 30.

    Compute the following limits.
    🔗

    (a)

    \begin{equation*} \lim_{x\rightarrow 2} \sqrt{x^2 + 1} - x^4 + 3x^3 - 1\text{.} \end{equation*}
    🔗
    🔗

    (b)

    \begin{equation*} \lim_{x\rightarrow 1} \frac{x^2 + 6x - 2}{2x^2 - 5}\text{.} \end{equation*}
    🔗
    🔗

    (c)

    \begin{equation*} \lim_{x\rightarrow -1} \frac{x^2 - x - 2}{x+3}\text{.} \end{equation*}
    🔗
    🔗
    🔗

    Indeterminate Forms.

    All of this before had a setup where the denominator was not zero. But what happens if it is? The direct substitution property does not apply here. However, in some cases, there may be something we can do.
    🔗

    Definition 31.

    An indeterminate form is a limit of the form
    \begin{equation*} \lim_{x \rightarrow a} \frac{f(x)}{g(x)} \end{equation*}
    where
    🔗
    🔗
     
    🔗
    In our case indeterminate means that the actual value of the limit is not determined by the expression when we just plug in \(a\text{.}\)
    🔗
    🔗

    Evaluating Indeterminate Limits.

    So, how can we try to evaluate these? The normal approach is to use algebraic simplification to reduce to a scenario where we can plug in the desired value and get something that is not indeterminate.
    🔗

    Example 32.

    Use algebraic simplification to compute the limit
    \begin{equation*} \lim_{x\rightarrow 3} \frac{x^2 - x - 6}{x-3} \end{equation*}
    🔗
    🔗
    🔗
    Be very careful with the notation in these limits. The expression and chain of steps need to make logical sense. In particular, you need to write “lim” at each step until you actually take the limit (that is, plug in the desired value).
    🔗

    Example 33.

    Evaluate
    \begin{equation*} \lim_{t\rightarrow 5} \frac{\sqrt{t+4}-3}{t-5}\text{.} \end{equation*}
    🔗
    🔗

    Example 34.

    Evaluate
    \begin{equation*} \lim_{x \rightarrow 2} \frac{x^2 - 4}{x^2 - 6x - 8}\text{.} \end{equation*}
    🔗
    🔗

    Other Limits to Evaluate.

    There are two other types of limits that we need to be careful about evaluating:
    • Piecewise Functions, and
      🔗
      🔗
    • Special Trigonometric Limits.
      🔗
      🔗
    🔗
    We’ll start with the trig limits. On the first worksheet, we had the first important trigonometric limit:
    \begin{equation*} \lim_{x\rightarrow 0} \frac{\sin(x)}{x} = 1\text{.} \end{equation*}
    From this, we can prove a second limit.
    🔗

    Example 35.

    Compute
    \begin{equation*} \lim_{x\rightarrow 0}\frac{\cos(x) - 1}{x}\text{.} \end{equation*}
    🔗
    🔗
    🔗

    Piecewise Functions.

    For piecewise functions, we need to care about all of the places that the function changes definition. At each of those, we’ll want to use one-sided limits to determine if the limit exists and what it is.
    🔗

    Example 36.

    Compute each of the following limits:
    🔗
    (a)
    \begin{equation*} \lim_{x\rightarrow 0} |x|\text{.} \end{equation*}
    🔗
    🔗
    (b)
    \begin{equation*} \lim_{x\rightarrow 0} \frac{x}{|x|}\text{.} \end{equation*}
    🔗
    🔗
     
    🔗
    🔗
    🔗

    Example 37.

    For the function
    \begin{equation*} f(x) = \begin{cases} (2-x)^2 & x < 3 \\ 4 & x = 3 \\ 4-x & x > 3 \\ \end{cases} \end{equation*}
    compute
    \begin{equation*} \lim_{x\rightarrow 3} f(x)\text{.} \end{equation*}

    Limits Involving Infinity.

    Our next few days will cover limits involving infinity. There are two main types of this:
    \begin{equation*} \lim_{x\rightarrow a} f(x) = \infty \quad \text{ and } \quad \lim_{x\rightarrow \infty} f(x) = L\text{.} \end{equation*}
    🔗
    🔗

    Limits “equalling” infinity.

    The key point with these limits is that they don’t exist. There is no real number that the function gets close to as \(x \rightarrow a\text{.}\) However, we use
    \begin{equation*} \lim_{x\rightarrow a} f(x) = \infty \end{equation*}
    as a shorthand notation.
    🔗
    How do we get functions to do this?
    🔗
    🔗
    Recall the definition of vertical asymptote from a previous class.
    🔗

    Example 38.

    Find all vertical asymptotes of
    \begin{equation*} f(x) = \frac{2x+3}{x^2 - x - 6}\text{.} \end{equation*}
    Determine the behavior of \(f(x)\) near these asymptotes.
    🔗
    🔗

    Example 39.

    Find all vertical asymptotes of
    \begin{equation*} f(x) = \frac{x^2 + 3x - 10}{2x^2 + 16x + 30}\text{.} \end{equation*}
    Determine the behavior of \(f(x)\) near these asymptotes.
    🔗
    🔗

    Example 40.

    Find all vertical asymptotes of
    \begin{equation*} f(x) = \frac{(x-3)(x+1)}{(x+4)(x-1)^2}\text{.} \end{equation*}
    Determine the behavior of \(f(x)\) near these asymptotes.
    🔗
    🔗

    Limits as \(x\) goes to infinity.

    Last time, we discussed limits where the “answer” was \(\pm\infty\text{.}\) This gave us vertical asymptotes of our functions. Now, we want to look at the other kind of limit involving infinity, one where the variable goes to infinity.
    🔗
    For a function \(f(x)\text{,}\) what does
    \begin{equation*} \lim_{x\rightarrow \infty} f(x) = L \end{equation*}
    mean or represent?
    🔗

    Definition 41.

    Let \(f(x)\) be a function defined on some interval \([a,\infty)\text{.}\) We say that
    \begin{equation*} \lim_{x\rightarrow \infty} f(x) = L \end{equation*}
    if

    🔗

    The line \(y=L\) is called a horizontal asymptote of the curve \(y = f(x)\) if

    One of the most common functions to look at with this kind of problem is powers of \(x\text{.}\)

    Example 44.

    Determine the value of
    \begin{equation*} \lim_{x\rightarrow \infty} \frac{1}{x} \text { and } \lim_{x\rightarrow \infty} \frac{1}{x^{5/2}}\text{.} \end{equation*}
