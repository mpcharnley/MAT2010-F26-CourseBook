    Introduction to Limits.

    The main concept that sets Calculus apart from Precalculus is the idea of a limit. Before, if we couldn’t plug something into a function, we just gave up. Now, we want to be a little more particular about that.
    🔗

    Example 3.

    Consider the function
    \begin{equation*} f(x) = \frac{x^2 - x - 2}{x-2}\text{.} \end{equation*}
    Investigate what \(f\) looks like near \(x=2\text{.}\)
    🔗
    🔗
    🔗

    Example 4.

    Consider the function
    \begin{equation*} f(x) = \frac{x^2 +4x + 5}{x-1}\text{.} \end{equation*}
    Investigate what \(f\) looks like near \(x=1\text{.}\)
    🔗
    🔗
    We want to have a mathematical way to distinguish between these two scenarios, one where it looks like there should be a value and one where there should not be. This is the idea of “approaching a value” is the idea of a limit.
    🔗

    Why care about this?

    It turns out that there are a surprising number of physical problems that revolve around this issue. We’ll cover two of them today.
    🔗
    🔗

    Example 5.

    Definition of a Limit.

    Now let’s try to give a bit more of a specific definition to this idea we’ve been hinting at so far. In some sense, we want to talk about the value of a function looks like it’s getting closer to as the input approaches a given value.
    🔗

    Definition 10 The Limit, attempt 1.

    Let \(f\) be a function defined around some point \(a\) (but not necessarily at \(a\)). We say that
    \begin{equation*} \lim_{x \rightarrow a} f(x) = L\text{,} \end{equation*}
    which is read “the limit of \(f(x)\) as \(x\) approaches \(a\) is \(L\)”,

    Limit Laws.

    The book lists out a bunch of laws for combining limits. I’ll put them all here for the sake of completeness, but you don’t really need to memorize them. The main rule is that if the operation is allowed on the limiting values, it generally works in the limit context.
    🔗

    Theorem 27.

    Let \(a\) and \(k\) be real numbers, and let \(f\) and \(g\) be functions such that
    \begin{equation*} \lim_{x\rightarrow a} f(x) = L \text{ and } \lim_{x\rightarrow a} g(x) = M \end{equation*}
    1. \(\displaystyle \lim_{x\rightarrow a} f(x) + g(x) = L + M\)
      🔗
      🔗
    2. \(\displaystyle \lim_{x\rightarrow a} f(x) \cdot g(x) = L \cdot M\)
      🔗
      🔗
    3. \(\displaystyle \lim_{x\rightarrow a} k\cdot f(x) = k \cdot L\)
      🔗
      🔗
    4. \(\lim_{x\rightarrow a} \frac{f(x)}{g(x)} = \frac{L}{M}\) as long as \(M \neq 0\)
      🔗
      🔗
    5. \(\lim_{x\rightarrow a} (f(x))^n = L^n\) for any positive integer \(n\)
      🔗
      🔗
    6. \(\lim_{x\rightarrow a} \sqrt[n]{f(x)} = \sqrt[n]{L}\) for any positive integer \(n\text{.}\) If \(n\) is even, then we also need \(L \geq 0\text{.}\)
      🔗
      🔗
