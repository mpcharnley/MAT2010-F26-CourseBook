    This is an outline of the topics we covered in Week 8 of the course, from October 19 to October 24.

    Applications of Implicit Differentiation.

    Example 132.

    Find all points on the graph of
    \begin{equation*} x^2 + 2y^2 = 9 \end{equation*}
    where the tangent line goes through the point \((5,1)\text{.}\)
    🔗
    🔗
    🔗

    Derivatives of Inverse Functions.

    Another main application of implicit differentiation is to finding the derivatives of inverse functions.
    🔗
    🔗
    So how can we actually use this?
    🔗

    Example 133.

    Find the derivative of
    \begin{equation*} f(x) = \log_b(x) \end{equation*}
    for any \(b\text{.}\)
    🔗
    🔗

    Example 134.

    Find the derivative of
    \begin{equation*} f(x) = \ln(x^2 + 2x^2 + 5) \end{equation*}
    🔗
    🔗

    Example 135.

    Find the derivative of
    \begin{equation*} f(x) = \ln(x^2 + 2x^2 + 5) \end{equation*}
    🔗
    🔗

    Example 136.

    Find the derivative of
    \begin{equation*} f(x) = \ln(x^{1/3}) \end{equation*}
    and
    \begin{equation*} g(x) = (\ln(x))^{1/3}\text{.} \end{equation*}
    🔗
    🔗

    Example 137.

    Find the derivative of
    \begin{equation*} f(x) = \ln\left(\frac{(x+3)^2}{\sqrt{x^2 + 4}}\right)\text{.} \end{equation*}
    🔗
    🔗

    Inverse Trigonometric Functions.

    The other kind of function we can apply this to is inverse trigonometric functions.

    Inverse Functions.

    A function takes an input and gives a single output. There are times where we want to “undo” this operation, and so we want an inverse function to do that. However, not all functions have inverses. What has to happen in order for there to be an inverse?
    🔗
    🔗
    So, if we have a one-to-one function, we then have an inverse function. What do we know about it?
    🔗
    How do we find this inverse?
    🔗

    Example 138.

    Find the inverse of the function \(f(x) = 5x-1\text{.}\) Verify that these functions are inverses.
    🔗
    🔗

    Example 139.

    Find the inverse of the function
    \begin{equation*} f(x) = \frac{3x - 5}{2x-7}\text{.} \end{equation*}
    Use this information to find the domain and range of both \(f(x)\) and \(f^{-1}(x)\text{.}\)
    🔗
    🔗

    Explicitly Defined Inverse Functions.

    There are a few functions that we use regularly that are more complicated than algebraic functions, so they have explicitly defined inverses.
    🔗
    The other common type of explicit inverse functions come from the trigonometric functions.
    🔗
    🔗

    Example 140.

    Find the inverse of the function \(f(x) = x^2\)
    🔗
    🔗
    🔗

    Making the Trigonometric Functions Invertible.

    Like we saw in the last example, sometimes we can make a non-invertible function work like one that is invertible by restricting the domain.

    Derivatives in Nature.

    When thinking about applications of the derivative to physical/real-world problems, the overarching theme is that the derivative is the rate of change of a function.
    🔗
    🔗

    Motion Problems.

    Example 149.

    Assume that the position of a remote-controlled car is given by
    \begin{equation*} s(t) = t^3 - \frac{23}{2}t^2 + 30 t \end{equation*}
    over the time interval \([0,10]\text{.}\)
    🔗
    (a)
    Where is the car at \(t=0\text{?}\)
    🔗
    🔗
    (b)
    Where is the car at \(t=2\text{?}\)
    🔗
    🔗
    (c)
    Find the velocity of the car at \(t=1\text{.}\)
    🔗
    🔗
    (d)
    When is the car at rest? Moving forward?
    🔗
    🔗
    (e)
    How would you compute the total distance traveled over the interval \([0,10]\text{?}\)
    🔗
    🔗
    (f)
    What is the acceleration at \(t=3\text{?}\)
    🔗
    🔗

    When is the car speeding up? Slowing down?
